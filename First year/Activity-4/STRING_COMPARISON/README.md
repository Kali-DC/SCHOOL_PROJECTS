# String Comparison

## Description
This program compares two strings entered by the user. It uses the `compare()` function and a relational operator to determine whether the strings are equal or which word comes first alphabetically.

## Concepts Used
- compare()
- Relational operators (==, <, >)
- if-else statements
- User input

## Sample Output
Enter the first word: Cat
Enter the second word: Dog
The first word comes first alphabetically.
