# Activity 4: String Operations in C++

## Overview
This activity demonstrates basic string operations using the C++ Standard Library's `std::string` class.

## Tasks
1. String Handling
2. String Concatenation
3. String Comparison
4. String Copying

<br>

- Declare and initialize string variables
- Accept string input from users
- Concatenate strings using different methods
- Compare strings using `compare()` and relational operators
- Copy and modify strings independently
