# Relational Operators

## Description

This program demonstrates the use of relational operators in C++. It compares values and produces Boolean results that indicate whether specific conditions are true or false. The output helps illustrate how comparisons are performed in programming.

## Concepts Used

- Relational Operators
- Equal To (`==`)
- Not Equal To (`!=`)
- Greater Than (`>`)
- Less Than (`<`)
- Greater Than or Equal To (`>=`)
- Less Than or Equal To (`<=`)
- Boolean Values
