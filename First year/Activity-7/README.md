# Activity 7: Selection Structures in C++

## Overview

This activity demonstrates the different selection structures used in C++. It explores how programs make decisions using conditional statements, relational operators, boolean operators, switch statements, and nested decisions. These concepts allow programs to execute different blocks of code based on specific conditions.

## Tasks

1. Selection Structures
2. Relational Operators
3. Boolean Operators
4. The if Statement
5. The if...else Statement
6. if...else if...else
7. The switch Statement
8. Nested Decisions

## Learning Outcomes

- Use `if` statements to execute code based on a condition
- Compare values using relational operators (`==`, `!=`, `>`, `<`)
- Apply boolean operators (`&&`, `||`, `!`) to combine and reverse conditions
- Implement `if...else` and `if...else if...else` structures for multiple outcomes
- Use `switch` statements to handle specific cases efficiently
- Create nested decision structures to evaluate multiple conditions
- Display boolean values using `boolalpha`
- Develop problem-solving skills through conditional programming scenarios
