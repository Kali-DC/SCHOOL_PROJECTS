# Activity 5: Typecasting in C++

## Overview

This activity demonstrates basic typecasting operations in C++. It explores both implicit and explicit typecasting, showing how values can be converted between different data types using automatic conversion and the `static_cast` operator.

## Tasks

1. Implicit Typecasting
2. Static Cast
3. Explicit Typecasting
4. Implicit vs Explicit Typecasting

<br>

- Perform automatic type conversion between compatible data types
- Convert values manually using the `static_cast` operator
- Display original and converted values
- Observe how data may change during conversions
- Compare implicit and explicit typecasting techniques
