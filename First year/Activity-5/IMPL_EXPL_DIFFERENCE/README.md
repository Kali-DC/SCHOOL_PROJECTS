# Implicit vs Explicit Typecasting

## Description

This program demonstrates the difference between implicit and explicit typecasting in C++. A `double` value is explicitly converted to an `int` using the `static_cast` operator, which removes the decimal portion and results in data loss. An `int` value is then implicitly converted to a `double` without losing any information. The program displays both conversions to compare their effects on the data.
