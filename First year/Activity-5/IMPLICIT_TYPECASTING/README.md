# Implicit Typecasting

## Description

This program demonstrates implicit typecasting by automatically converting an `int` value to a `float` value and a `char` value to an `int` value without using explicit casting. The original and converted values are displayed to show how automatic type conversion works in C++.

## Concepts Used

- Implicit Typecasting
- int → float conversion
- char → int conversion
- Data type conversion
- cout output
