# Static Cast

## Description

This program demonstrates explicit typecasting in C++ using the `static_cast` operator. It converts a `double` value into an `int` value, causing the decimal portion to be removed during the conversion. The program displays both the original and converted values to illustrate how explicit typecasting works.

## Concepts Used

- Explicit Typecasting
- static_cast
- double → int conversion
- Data type conversion
- cout output
