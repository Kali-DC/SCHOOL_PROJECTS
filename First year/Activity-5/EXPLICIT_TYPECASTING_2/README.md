# Explicit Typecasting

## Description

This program demonstrates explicit typecasting in C++ using the `static_cast` operator. It converts an integer value into a character and another integer value into a float. The program displays both the original and converted values to show how different data types can represent the same value in different ways.

## Concepts Used

- Explicit Typecasting
- static_cast
- int → char conversion
- int → float conversion
- Data type conversion
- cout output
